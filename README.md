# 📂 Project Datasets
This project utilizes several variations of the AgeDB dataset and custom-generated video content. Below are the descriptions and access links for each data subset used in our experiments.

## 1. AgeDB (Original)
The primary source dataset containing "in-the-wild" facial images labeled by subject name, age, and gender. This serves as the foundation for all subsequent processing and sampling.

Source: [AgeDB Research Paper/Official Link]

Link: https://drive.google.com/drive/folders/1Y4IaxLK9NBftxko5pGj620NX-o4LD0wB?usp=sharing

## 2. Downsampled Subset (50 Subjects)
A filtered version of the original dataset containing 50 unique subjects. This subset was created to streamline testing and ensure a diverse representation of individuals without the computational overhead of the full dataset.

Selection Method: Random sampling of 50 eligible subjects.

Link: https://drive.google.com/drive/folders/1V9u-7rwWDSRVOUHFLk7GNlv6TLaLORDt?usp=drive_link

## 3. Frontal ID Images (50 Subjects)
A curated collection of "ID-style" photos. This dataset extracts exactly one image for each of the 50 subjects, specifically selected for high symmetry (frontal pose), sharpness, and optimal face-to-frame ratio.

Selection Method: MTCNN-based landmark symmetry and Laplacian variance scoring.

Link:  https://drive.google.com/drive/folders/1-pRnnFJucrb4LEuQ8aCgPqXtihtR7svy?usp=drive_link
## 4. Driving Videos
A collection of source videos providing the motion and facial expressions used for animation. These videos serve as the "drivers" for the first-order motion models or deepfake synthesis pipelines.

Content: Facial movements, eye blinks, and head rotations.

Link: https://drive.google.com/drive/folders/1aHni-cBZ--b7ZtE7Vx1UEj36stLHEXfz?usp=drive_link

## 5. Synthetic Video Dataset (Generated)
The final output dataset. These videos are generated by applying the motion from the Driving Videos to the static faces in the Downsampled Subset. This demonstrates the model's ability to animate diverse subjects.

Details: 50 generated video clips (one per subject).

To reproduce the results, download the datasets and place them in the /data directory following the structure outlined in the Environment Setup section.
